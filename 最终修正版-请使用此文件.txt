macro_command main()
// ============================================================
// 功能：批量读取 Modbus 网关寄存器，映射到本地位地址
// 设备：Modbus网关45
// 读取：3x149, 3x152, 3x155, 3x158, 3x161
// 映射：LB60, LB61, LB62, LB63, LB64
// ============================================================

short buf[13]
short result
short i

// 初始化缓冲区
for i = 0 to 12
  buf[i] = 0
next i

// 批量读取 Modbus 寄存器
result = GetData(buf, "Modbus网关45", ReadHoldingReg, 148, 13)

if result == 1 then
  // 读取成功，开始处理数据
  
  // 3x149 -> LB60
  if buf[0] > 0 then
    SetData(1, "local", LB, 60, 1)
  else
    SetData(0, "local", LB, 60, 1)
  end if
  
  // 3x152 -> LB61
  if buf[3] > 0 then
    SetData(1, "local", LB, 61, 1)
  else
    SetData(0, "local", LB, 61, 1)
  end if
  
  // 3x155 -> LB62
  if buf[6] > 0 then
    SetData(1, "local", LB, 62, 1)
  else
    SetData(0, "local", LB, 62, 1)
  end if
  
  // 3x158 -> LB63
  if buf[9] > 0 then
    SetData(1, "local", LB, 63, 1)
  else
    SetData(0, "local", LB, 63, 1)
  end if
  
  // 3x161 -> LB64
  if buf[12] > 0 then
    SetData(1, "local", LB, 64, 1)
  else
    SetData(0, "local", LB, 64, 1)
  end if
  
else
  // 读取失败，清零所有位
  SetData(0, "local", LB, 60, 1)
  SetData(0, "local", LB, 61, 1)
  SetData(0, "local", LB, 62, 1)
  SetData(0, "local", LB, 63, 1)
  SetData(0, "local", LB, 64, 1)
end if

// LB65 固定清零
SetData(0, "local", LB, 65, 1)

end macro_command

修正说明 v1.2：
---------------

✅ 修正 1：GetData 缓冲区参数
   - 第 19 行：buf（不是 buf[0]）

✅ 修正 2：SetData 设备名称
   - 所有行：使用 "local"（不是 "Local HMI"）

✅ 修正 3：for 循环结束语句（新增修正）
   - 第 16 行：使用 next i（不是 end for）
   - 原因：威纶通宏的 for 循环必须用 next 结束

关键语法规则：
--------------

1. for 循环语法：
   for i = 0 to 12
     // 循环体
   next i          ← 必须用 next，不能用 end for

2. GetData 语法：
   GetData(数组名, "设备名", 地址类型, 起始地址, 数量)
           ^^^     不能是 数组名[0]

3. SetData 本地位语法：
   SetData(值, "local", LB, 地址, 数量)
               ^^^^^^^  必须小写

验证步骤：
----------

1. 在 EBPro 中：编辑 → 宏
2. 如果已有宏，清空所有内容
3. 复制上面的代码（从 macro_command 到 end macro_command）
4. 粘贴到宏编辑器
5. 点击"编译"
6. 应该显示：编译成功或 0 error(s) 0 warning(s)

如果仍有错误：
--------------

1. 确认设备名称：
   系统参数 → 设备 → 通讯设备
   确认名称是否为 "Modbus网关45"（区分大小写）

2. 如果设备名称不同，请修改第 19 行：
   result = GetData(buf, "你的实际设备名", ReadHoldingReg, 148, 13)

3. 确认 EasyBuilder Pro 版本：
   推荐使用 V6.00 或以上
