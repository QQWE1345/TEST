================================================================================
威纶通宏语法核心规则
================================================================================

1. GetData 语法：
   GetData(数组名, "设备名", 地址类型, 起始地址, 数量)
           ^^^^^^ 必须是数组名，不能是 数组名[0]

2. SetData 本地位语法：
   SetData(值, "local", LB, 地址, 数量)
               ^^^^^^^ 必须小写，区分大小写

3. for 循环语法：
   for 变量 = 起始 to 结束
     // 循环体
   next 变量     ← 必须用 next，不能用 end for
   ^^^^^^^^^

完整对比示例
================================================================================

❌ 错误版本：
----------------
for i = 0 to 12
  buf[i] = 0
end for

result = GetData(buf[0], "Modbus网关45", ReadHoldingReg, 148, 13)

if buf[0] > 0 then
  SetData(1, "Local HMI", LB, 60, 1)
end if

✅ 正确版本：
----------------
for i = 0 to 12
  buf[i] = 0
next i

result = GetData(buf, "Modbus网关45", ReadHoldingReg, 148, 13)

if buf[0] > 0 then
  SetData(1, "local", LB, 60, 1)
end if

================================================================================
常见问题
================================================================================

Q1: 还是有 error C45 错误？
A1: 确认设备名称：系统参数 → 设备 → 通讯设备
    检查是否为 "Modbus网关45"（区分大小写）

Q2: 还是有 error C38 错误？
A2: 确认第 22 行是 GetData(buf, ...) 而不是 GetData(buf[0], ...)
    可能复制了旧版本，请重新复制最新代码

Q3: 还是有 error C21 错误？
A3: 确认第 16 行是 next i 而不是 end for
    威纶通宏必须用 next 结束 for 循环

Q4: 有多个 error C31（参数类型不正确）？
A4: 这通常是上述错误的连锁反应
    修正 C38、C45、C21 后，C31 会自动消失

Q5: 还有其他错误？
A5: 可能原因：
    - EBPro 版本过低（需要 V6.0+）
    - 代码复制不完整
    - 有隐藏的特殊字符
    建议：完全删除宏，重新创建并粘贴
