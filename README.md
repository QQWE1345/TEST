# 威纶通 Modbus 寄存器到本地位映射项目

## 📁 项目文件

### 1. `modbus_to_local_bit.txt` ⭐⭐⭐
**威纶通 EasyBuilder Pro 宏脚本** - 可直接在宏编辑器中使用

**功能**：
- 批量读取 Modbus 网关的 5 个寄存器（3x149、3x152、3x155、3x158、3x161）
- 根据寄存器值映射到本地位地址（LB60-LB64）

- 优化通讯：一次读取 13 个寄存器，减少通讯开销

**语法**：100% 符合 EasyBuilder Pro 宏语法规范

- **推荐**：定时触发（1000ms 周期）

### 步骤 4：验证
- 在画面上添加 LB60-LB65 的位状态指示灯
- 观察寄存器值变化时，对应 LB 位是否正确置位/清零

## ⚙️ 配置要求

| 项目 | 要求 |
|-----|------|
| HMI | 威纶通 EasyBuilder Pro |
| 设备名称 | `Modbus网关45`（必须与通讯设备列表一致）|
| Modbus 地址 | 3x149、3x152、3x155、3x158、3x161 |
| 本地位地址 | LB60、LB61、LB62、LB63、LB64、LB65 |
| 通讯协议 | Modbus RTU/TCP |

---

## 🔧 核心逻辑

```
读取 Modbus 3x149~3x161（13 个寄存器）
  ↓
提取 buf[0], buf[3], buf[6], buf[9], buf[12]
  ↓
判断每个值是否 > 0
  ↓
置位或清零对应的 LB60-LB64
  ↓
LB65 固定清零
```

---

## 📋 映射关系

| Modbus 寄存器 | 条件 | 本地位 |
|--------------|------|-------|
| 3x149 > 0    | ✓    | LB60 = 1 |
| 3x149 ≤ 0    | ✓    | LB60 = 0 |
| 3x152 > 0    | ✓    | LB61 = 1 |
| 3x152 ≤ 0    | ✓    | LB61 = 0 |
| 3x155 > 0    | ✓    | LB62 = 1 |
| 3x155 ≤ 0    | ✓    | LB62 = 0 |
| 3x158 > 0    | ✓    | LB63 = 1 |
| 3x158 ≤ 0    | ✓    | LB63 = 0 |
| 3x161 > 0    | ✓    | LB64 = 1 |
| 3x161 ≤ 0    | ✓    | LB64 = 0 |
| -            | 固定 | LB65 = 0 |

## 📞 技术要点

### 威纶通宏语法特点
- 使用 `macro_command main()` ... `end macro_command`
- 不使用分号 `;`
- `if-then-else-end if` 结构必须换行
- `GetData` 批量读取语法
- `SetData` 写入本地位语法

### 优化设计
- **批量读取**：一次通讯获取 13 个寄存器
- **减少通讯**：相比单独读取减少 80% 开销
- **错误处理**：包含读取失败时的清零逻辑
